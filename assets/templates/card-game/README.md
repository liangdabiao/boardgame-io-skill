# ☯ 西游斗法 · 卡牌对战

以《西游记》为题材的类游戏王卡牌对战小游戏，基于
[boardgame.io](https://boardgame.io) (v0.50.x) 构建，是
boardgame-io skill `card-game` 模板的第二个实战项目。
**全部 13 张卡面图由 apiz（nano-banana-2 模型）生成。**

**人机对战模式**：你执「取经人」（玩家 0），AI 执「妖魔主」（玩家 1）。
AI 为脚本机器人（`src/bot.js`），决策逻辑与整局自动对局测试同源：
法力吃紧喝人参果、有目标念紧箍咒、墓地有货吃还魂丹、召唤最强神魔、
斗法只打稳赢或等值互换的目标（打不过按兵不动）、对方空场直取元神。
每个动作间隔约 0.75 秒，便于观看。

**音效与动效**：
- BGM 为 apiz（`minimax/music-gen`）生成的 37 秒国风战斗曲（古筝+笛子+
  太鼓），循环播放，首次交互后启动（浏览器自动播放策略）
- 8 种合成音效（`src/sfx.js`，Web Audio 实时合成、零资源）：召唤锣声、
  攻击斩击、受击钝响、法术琶音、抽牌、消散、回合钟磬、胜利号角/落败挽歌
- 动效（`board.jsx` FX 差分引擎 + CSS 关键帧）：召唤弹性进场、攻击
  突进（我方向上/敌方向下）、伤害飘字、大额伤害震屏、消散入墓、
  终局金光/沉落、轮到你时玩家标签呼吸、可用手牌光晕呼吸
- 工具栏「🎵 音乐」「🔊 音效」独立开关，偏好存 localStorage

## 运行

```bash
npm install
npm run dev     # http://localhost:5173
npm test        # 28 个测试：规则 + 整局自动对局 ×5 + AI 决策与人机集成
```

页面为单个取经人视角（AI 手牌同样经 playerView 隐藏，只显示牌背），
你操作时 AI 等待，AI 回合自动行动。

## 规则（简化版游戏王 × 西游记包装）

- 双方法力（LP）8000，共用 23 张卡表各洗一副；开局各摸 5 张
- 每回合开始自动抽 1 张；**法力归零或卡组抽干判负**
- 回合 = 主要阶段（召唤/法术）+ 斗法阶段（攻击）；先手首回合不能攻击
- **通常召唤**每回合 1 次：≤4★ 直接召唤；5-6★ 需 1 祭品；7★+ 需 2 祭品
  （祭品自动选场上攻击力最低的神魔，可召到祭品腾出的槽位）
- **斗法**：攻击力高者破坏对方并造成差额伤害；低者反被破坏；相同同归于尽；
  对方空场时可**直取元神**

## 卡面图再生成

```bash
bash scripts/gen-cards.sh   # 用 apiz (fal-ai/nano-banana-2) 重新生成 13 张卡图
```

统一风格 prompt（国风工笔重彩 + 鎏金暗纹边框、竖版 3:4）见脚本内
`STYLE`；单张约 60-80 积分。

## 结构

`src/cards.js` 卡池 → `src/game.js` 纯规则（含紧箍咒单体破坏效果）
→ `src/board.jsx` 一键交互 + 状态反馈行 + 卡面图 → `src/index.jsx`
Local() 双视角客户端。图片用 Vite `new URL(..., import.meta.url)`
资产模式引入——打包器与纯 Node 测试环境都兼容。
